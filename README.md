# Etheris official website (local)

Static Ocean Glass / Neo-Aero site. No build step required.

```bash
cd ~/etheris-os/website
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

**Not publicly deployed.** No domain, DNS, or hosting changes without owner approval.
Fonts are self-hosted. No analytics.
