# Etheris official website

Static Ocean Glass / Neo-Aero site. No build step required.

**Live site:** https://saarniuimonen-beep.github.io/etheris-website/

Hosted with GitHub Pages from the `main` branch.

## Local preview

```bash
cd ~/etheris-website
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

Fonts are self-hosted. No analytics.
