Community & support

Public channels for a public alpha. No SLA — best-effort.

Where to talk

  • GitHub Issues — bugs, hardware reports, feature requests
  • GitHub Discussions — questions and ideas (when enabled)
  • Source repository — pull requests welcome after Issues discussion
  • Website — download and project overview
Alpha builds are unsupported for production. Include etheris doctor output when filing bugs (strip secrets).

What helps most

  • VM smoke results and physical hardware rows for the test matrix
  • Clear reproduce steps and ISO SHA256
  • Honest “works / broken” notes for Wi‑Fi, GPU, and Bluetooth adapters
