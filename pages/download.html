System requirements

  • 64-bit PC (x86_64), UEFI or BIOS
  • About 4 GB RAM recommended for desktop + browser
  • GPU with working Mesa or NVIDIA drivers for Wayland
  • About 20 GB free disk space for a practical install

Before you install

  • Read known issues in the project docs
  • Check the SHA256 checksum after download
  • Try it in a virtual machine before using a real disk
  • Only listed hardware has been tested
