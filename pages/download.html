System requirements

  • 64-bit x86_64 UEFI or BIOS
  • ~4 GiB RAM recommended for desktop + browser
  • GPU with working Mesa or NVIDIA drivers for Wayland
  • Storage: enough for Arch root + home (20 GiB+ practical)

Before you install

  • Read known issues in project docs
  • Verify checksums after download
  • Test in a VM before touching physical disks
  • Hardware matrix rows are evidence-based only
