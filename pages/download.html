Get Etheris OS

  • Version: 0.1.0-alpha (public development)
  • Release: v0.1.0-alpha on GitHub
  • Image: etheris-2026.11.19-x86_64.iso (~2.2 GiB)
  • Checksums: download SHA256SUMS from the release and verify before writing USB
  • Source: github.com/saarniuimonen-beep/etheris-os

GitHub’s per-file limit is 2 GiB, so the ISO may be linked from a mirror or built with ./build.sh. The release always publishes SHA256SUMS and release notes. Always verify the hash.

Open releases Getting started Source code

System requirements

  • 64-bit PC (x86_64), UEFI or BIOS
  • About 4 GB RAM recommended for desktop + browser
  • GPU with working Mesa or NVIDIA drivers for Wayland
  • About 20 GB free disk for a practical install

Before you install

  • Read Getting started
  • Verify SHA256 after download
  • Try a virtual machine before using a real disk
  • Keep backups — alpha builds can break

Build from source

git clone https://github.com/saarniuimonen-beep/etheris-os.git
cd etheris-os
./build.sh
# → out/etheris-*.iso + out/SHA256SUMS

Needs Podman and about 12–20 GB free. Details in the project README.
