Features

What works today, what is experimental, and what is still planned.

Etheris desktop — available

Sway, top panel, app launcher, graphical login, wallpaper app, Control Center, and Settings.

Performance Manager — available

Four profiles. Only options your hardware supports are shown. Real GPU effects still need testing on physical machines.

GPU Manager — available

Finds NVIDIA, AMD, and Intel graphics, suggests drivers, and keeps performance settings in sync.

Gaming stack — available

Steam, Proton helpers, 32-bit libraries, and GameMode. No anti-cheat bypass tools.

Low idle memory — goal

About 500 MB with a basic Sway session. Extra apps do not count toward that goal. Check with etheris ram idle-check.

Installer / first-boot setup — partly tested

Works in virtual-machine tests so far. More testing before calling install media release-ready.

Read-only system — early work

On Btrfs, /usr can be remounted read-only for experiments. Full safe A/B updates are not included yet.
