Features

Available, experimental, and planned — labeled honestly.

Neo-Aero desktop — available

Sway, Waybar, Rofi launcher, ReGreet, wallpaper app, Control Center, Settings.

Performance Manager — available

Four profiles with capability detection. Physical GPU effects need hardware verification.

GPU Manager — available

Detection via etheris-hw, driver recommendations via etheris-drivers, linked performance profiles.

Gaming stack — available

Steam, Proton helpers, multilib, GameMode. Anti-cheat bypasses are intentionally absent.

Lean idle RAM — target

≤500 MiB session RSS with Sway + lean Firefox preload (`etheris ram idle-check`). Extra apps are out of scope for the gate.

Installer / OOBE — partially verified

Prior milestone VM passes; keep testing before calling install media release-ready.

Immutable-prep — foundation

Btrfs installs can remount /usr read-only with developer-mode unlock. Full A/B atomic updates are not shipped yet.
