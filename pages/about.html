About Etheris

A lightweight Arch-based Wayland distribution with a distinctive Neo-Aero desktop and practical system tools.

Goals

Etheris aims to be usable day-to-day: clear branding, a coherent desktop, honest hardware support, and tools for performance, gaming, and development without exaggerated marketing.

Design philosophy

Neo-Aero / Ocean Glass — luminous cool air, water, and soft glass. Selective transparency, restrained motion, and readable contrast. True compositor blur is not claimed on Sway.

Technical foundation

Arch Linux packages, systemd, pacman, Sway as the default compositor, and optional Archive lag channels for calmer updates. Installs are mutable today; immutability remains planned.

Privacy

No telemetry by default. Firewall on. SSH not enabled by default. See the security documentation for limitations — Etheris does not claim to be “completely secure.”

Current status

Etheris is 0.1.0-alpha. Live desktop features are under active testing. Public repositories and download hosting await owner approval after integration verification.
