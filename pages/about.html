About Etheris OS

An independent Arch-based Wayland Linux distribution with a themed Sway desktop and practical system tools.

Independence

Etheris OS is a standalone Linux distribution project. It is not affiliated with, endorsed by, or related to Etheris Labs, Etheris AG, Etheris Chile (invoicing), AETHERIS, or any other company or product that uses the name Etheris.

Goals

Etheris OS aims to be usable day-to-day: a consistent desktop, tested hardware notes, and tools for performance, gaming, and development — without overselling.

Look and feel

Ocean Glass is the default theme: cool blues, soft transparency, calm motion, and readable text. Panels can look see-through; full-screen blur is not claimed on Sway.

Technical foundation

Based on Arch Linux (pacman, systemd). Default desktop is Sway. The stable update channel uses packages that are a bit older than Arch’s newest ones, for calmer updates. You can change the install freely today; a read-only “immutable” mode is only planned.

Privacy

No telemetry by default. Firewall on. SSH not enabled by default. See the security docs for limits — Etheris does not claim to be “completely secure.”

Current status

Etheris is 0.1.0-alpha. The live desktop is still being tested. Public downloads and GitHub links are not published yet.
