Development

Active 0.1.0-alpha development. Source and this site are on GitHub.

Repositories

  • etheris-os — ISO profile, desktop, installer, docs
  • etheris-website — this site
Repos remain experimental. A public ISO download host is not published yet — build locally with ./build.sh.

Build

Build the ISO with Podman: ./build.sh. Tests run in a user-session QEMU VM and should not change your host system.

Recent progress (through 2026-11-15)

  • Desktop polish: Menu, launcher, greeter, Ocean Glass / Flow tokens
  • QEMU rock-solid gates: stability, reliability, security, bugs, idle RAM (~169 MiB)
  • Installer persistence and optional LUKS unlock E2E
  • Software Center, doctor, source CI checks

Still open

  • Physical GPU / hardware matrix evidence
  • Secure Boot and signed public releases
  • Installer recovery polish and public ISO hosting
