Etheris

An Arch-based Wayland system with a Neo-Aero desktop — luminous, efficient, and honest about what works today.

Get Etheris Read the docs

Built for everyday clarity

Etheris ships a coherent Sway desktop, practical system tools, and performance controls that only expose hardware-supported options.

Neo-Aero desktop

Ocean Glass atmosphere, floating panel or dock, Rofi launcher, ReGreet login, and Settings that stay out of the way.

Performance Manager

Four profiles — Maximum, Balanced, Quiet, Power Saving — applied through safe CPU and GPU interfaces. No overclocking.

GPU Manager

Detect NVIDIA, AMD, and Intel graphics, review driver recommendations, and keep performance settings consistent.

Gaming-ready stack

Steam, Proton helpers, multilib, and GameMode where appropriate — without anti-cheat bypass tooling.

Privacy defaults

No telemetry by default, nftables on, SSH off unless you enable it. Security claims stay limited and documented.

Arch foundation

pacman, rolling packages with optional Archive lag channels, and a lightweight installer path under active testing.

Efficiency without empty promises

The ~500 MB idle RAM target remains aspirational. Etheris prefers a usable desktop over stripping security, drivers, or reliability.

Hardware compatibility is documented only with evidence. Untested hardware is marked untested.
