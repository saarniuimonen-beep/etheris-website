Etheris OS

An independent Arch-based Wayland Linux distribution with a clear Sway desktop. Light on resources, and clear about what works today.

Get Etheris OS Read the docs

Built for everyday use

Etheris ships a ready Sway desktop, practical system tools, and performance controls that only show options your hardware supports.

Etheris desktop

Ocean Glass theme, panel or dock, Rofi launcher, graphical login, and Settings that stay out of the way.

Performance Manager

Four profiles — Maximum, Balanced, Quiet, Power Saving — applied through safe CPU and GPU interfaces. No overclocking.

GPU Manager

Detect NVIDIA, AMD, and Intel graphics, review driver recommendations, and keep performance settings consistent.

Gaming-ready stack

Steam, Proton helpers, multilib, and GameMode where appropriate — without anti-cheat bypass tooling.

Privacy defaults

No telemetry by default, nftables on, SSH off unless you enable it. Security claims stay limited and documented.

Arch foundation

pacman, rolling packages with optional Archive lag channels, and a lightweight installer path under active testing.

Light on memory — without cutting corners

The ~500 MB idle RAM target is a goal, not a guarantee. Etheris keeps a usable desktop rather than removing security, drivers, or reliability.

Hardware support is listed only when it has been tested. Untested hardware is marked untested.
